Scope Sanko uses
Table 2 heads its local-name column "Local Name (Yoruba)" and is unnumbered, so the row locator is the ordinal position. Parts and preparations are joined from Appendix Table A1 by species. Two entries printed in the Yoruba column are not Yoruba names (bamboo; Ugu, which is Igbo) and are kept as published text without becoming mappings. The runtime index uses the name mappings, parts and preparations, not the cough indication or the fidelity indices.
