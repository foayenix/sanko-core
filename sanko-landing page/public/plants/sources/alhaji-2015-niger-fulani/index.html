Scope Sanko uses
Fulani pastoralists in nine pastoral communities across Niger State. Table 2 marks each local name with a superscript H, F or N (Hausa, Fulani, Nupe per the footnote); F is recorded as Fulfulde (ff). The use reported is ethnoveterinary, on cattle; only the name mappings are used, not the disease indications or the preparations. Row 14 (Khaya senegalensis) repeats the botanical name in the local-name column and yields no mapping. No voucher specimens are reported.
