Scope Sanko uses
The first Ijaw source in the index, and the second South-South one. Table 2 prints the English common name and the Ijaw name in a single cell separated by a slash, in either order and sometimes only one of the two, so scripts/extract-bayelsa-survey.js lists the thirty-six English names read off the table and treats everything else in the cell as Ijaw; the cell is kept verbatim in vernacular_as_published. Two cells yield no Ijaw name: 'Hospital too far' is the Nigerian English by-name for Jatropha tanjorensis, and 'Native pop' an English name for Ficus lutea. Table 3 gives preparation and treatment in prose rather than a parts column, so no plant parts are claimed, and its therapeutic text is not exported. Ingested on the same terms as sonibare-2008-anti-asthmatic: freely readable with no reuse licence stated anywhere, and only the published name mappings are used.
