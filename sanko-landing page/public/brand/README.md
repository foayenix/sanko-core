# Sanko brand assets

The active Sanko identity is the D1 Source Mark paired with the uppercase SANKO wordmark. `BRAND_IDENTITY.md` at the repository root contains the governing rules.

## Use

- Dark indigo surfaces: `sanko-lockup-on-dark.svg` or `sanko-source-mark-on-dark.svg`.
- Mineral-white surfaces: `sanko-lockup-on-light.svg` or `sanko-source-mark-on-light.svg`.
- Wordmark-only use: only where the D1 mark is already present nearby.
- Shared visual overview: `sanko-brand-board.svg`.
- Interface tokens: `sanko-brand-tokens.css`.

## Restrictions

- Do not combine these assets with the legacy bird, monogram or seal.
- Do not recolour the logo chartreuse.
- Do not use the seal as a trust, evidence, governance or certification mark.
- Do not change the D1 geometry without a documented brand-version update.

The lockup SVGs reference `../fonts/archivo-variable.woff2`. Preserve that relative relationship inside the web project. Convert the wordmark to outlines for external packaging or design-tool distribution.
